Privacy Policy

KANTA Claude Drive (the "app") is a private desktop tool used by a single Google account owner on their own computer. This policy explains how the app handles Google user data. Effective 11 November 2026.

Data the app accesses

With the owner's permission, the app accesses the owner's Google Drive files and folders, Google Docs and Google Sheets (scopes: Google Drive, Google Docs, Google Sheets).

How the data is used

The data is used only to carry out the owner's own requests: listing and searching files, downloading files to the owner's computer, reading document and spreadsheet content, and uploading or updating files in the owner's Drive.

Storage

Downloaded files and the sign-in token are stored only on the owner's own computer. The app has no server and keeps no copy of the data anywhere else.

Sharing

The app does not sell, rent, share, or transfer Google user data to anyone. It does not use the data for advertising, and it does not use the data to train artificial-intelligence models.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends the app's access.

Contact

Questions about this policy can be sent to the support email shown on the app's Google sign-in screen.
