KANTA Claude Drive

KANTA Claude Drive is a private desktop tool. It is used by one Google account owner on their own computer, so that a desktop assistant can work with that owner's own Google Drive, Google Docs and Google Sheets files.

What it does, always at the owner's request:

  • lists and searches files in the owner's Drive folders;
  • downloads files to the owner's computer, and reads Docs and Sheets content;
  • uploads finished files back to the owner's Drive, or updates the owner's own Docs and Sheets.

The tool is not offered to the public and has no other users.
